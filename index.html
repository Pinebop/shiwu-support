拾物

给每件物品一个位置、一个名字、一段记忆。

版本 0.1（发版前更新） iOS 17 或更高 iPhone

关于

拾物是一个纯本地的物品整理 App：收集、整理、分类、查找、归档你拥有的东西。 新增一件物品的第一动作是拍照，照片是最自然的索引；位置记到「卧室 · 床头抽屉」 这样的两级；卖掉、送走的物品收进「旧物志」，可以留一句话给它。

拾物没有账号、没有服务器、不联网：所有数据只存在这台 iPhone 上， 随时可以导出 CSV 清单（保险 / 搬家）或 JSON 全量备份。

功能

拍照即收录

新增物品先拍照，也可以不用照片、只记名字和分类。

fzf 式查找

输入即搜，支持拼音首字母（kh 找到口红），名称、分类、标签、位置、备注都在范围内。

位置两级

「卧室 · 床头抽屉」，下次找不到东西时先问拾物。

旧物志

归档不是删除：拍立得卡片墙留住所物与所忆，误归档可取回。

分类自定制

15 个内置分类 + 二级子类，也能自建；在用的分类删了也不丢物品——自动解绑。

八种界面语言

简体中文、英语、法语、俄语、西班牙语、阿拉伯语、韩语、日语。

常见问题

我的数据存在哪里？

全部在本机 App 沙盒的 Application Support/things 目录（物品 JSON + 照片文件）。没有服务器副本，删除 App 即一并删除——想留底请先用「设置 → 导出与备份」 生成 CSV 清单或 JSON 全量备份，保存在你自己选的位置。

这个 App 会联网吗？都传了什么？

不联网。拾物不发起任何网络请求：没有账号体系、没有统计或广告 SDK、 没有崩溃上报。详见隐私政策。

怎么备份 / 换手机迁移？

「设置 → 导出与备份」可以生成 CSV 清单（保险、搬家场景）或 JSON 全量备份 （含全部物品、照片引用与分类体系）。换机迁移的导入功能在后续版本中。

首次启动弹出「无线数据 / 网络」询问，这个 App 要联网吗？

不要紧。拾物不发起任何网络请求，这个提示是国行 iPhone 系统对每个 App 首次启动的统一询问（运营商要求），与 App 本身是否联网无关。 选「不允许」也完全不影响使用——拾物的全部数据只存在本机。 详见隐私政策。

遇到崩溃 / 打不开怎么办？

先试：① 退出 App 重新打开；② 重启手机；③ 若需删除重装，请先导出 JSON 备份（重装后本机数据无法找回）。仍解决不了请到下方 GitHub Issues 反馈， 并附上设备机型、系统版本、App 版本与复现步骤。
