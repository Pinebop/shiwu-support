隐私政策

拾物

生效日期：2026-10-04 · 适用于：拾物（App Store 发行版）

一句话版本

拾物不收集、不上传、不追踪：它不发起任何网络请求，你记录的所有内容 （物品、照片、分类体系）只存在这台 iPhone 的应用沙盒里，只有你自己能看到。

1. 我们收集哪些信息

不收集。拾物没有账号体系，不做用户画像，不做广告或跨应用追踪， 也没有接入任何统计、广告或崩溃上报类的第三方 SDK。这与 App 内置的 隐私清单（PrivacyInfo.xcprivacy：不追踪、采集数据类型为空）以及 App Store 的「App 隐私」标签口径一致。

2. 数据存在哪里

全部数据只存在本机 App 沙盒内：

  • 物品记录（含名称、分类、标签、位置、备注）：Application Support/things/items 下的 JSON 文件；
  • 照片（原图与缩略图）：Application Support/things/photos/；
  • 分类体系快照与相关设置：同一沙盒内的本地文件与系统 UserDefaults。

没有服务器副本。删除 App 时，以上数据随沙盒一并删除； 「设置 → 导出与备份」生成的 CSV / JSON 备份文件保存在你选择的位置，由你自行保管。

3. 联网行为

拾物不发起任何网络请求：没有账号登录、没有同步、 没有统计或广告请求、没有崩溃上报，也没有加载任何远程资源。 （这句话对应代码现状；App 的联网 / 存储行为发生变化时，我们会同步更新本政策。）

4. 设备标识

不使用。拾物不读取广告标识符（IDFA）、厂商标识符（IDFV）或任何其他设备标识， 因此也不存在基于标识符的跨应用追踪。

5. 系统权限

拾物只申请一项系统权限：

  • 相机——用于给物品拍照，方便记录和查找。 仅在你主动点「拍照收录 / 添加照片」时使用，不会在后台调用。

从相册选图走系统的照片选择器（PHPicker），由系统出界面、你在系统面板里挑选， 拾物不申请整个相册库的访问权限，也读不到你未挑选的照片。

6. 第三方组件

无。拾物的全部代码为自研 Swift 模块，不包含第三方统计、广告、 追踪或崩溃上报组件。

7. 购买与订阅

拾物目前完全免费，无应用内购买、无订阅。若未来引入付费功能， 支付将由 Apple（App Store / StoreKit）处理，开发者接触不到你的支付信息， 并会先更新本政策。

8. 数据保留与删除

你的数据只存在本机：删除某个物品即从本机删除其记录与照片文件； 删除 App 即删除全部本机数据。拾物没有服务器，因此不存在服务端留存； 你通过 GitHub Issues 联系我们时留下的内容，由 GitHub 按 GitHub 的隐私政策处理。

9. 儿童隐私

拾物不收集任何用户数据，因此也不收集儿童数据。家长可以放心让孩子使用。

10. 政策变更

本政策内容与 App 实际行为绑定：当 App 的联网、存储或权限行为发生变化时， 我们会在同一个版本内更新本页并修改顶部的生效日期。

11. 联系我们

对本政策或隐私实践有任何疑问，请 在公开仓库提交 issue， 或发邮件到 kenshinlzh@163.com。
